# NEBCA Fishing + Harbour First Deployment

This branch reframes the first commercial NEBCA installation around a fishing company and harbour-integrated operating environment.

## Delivery principle

NEBCA Core is established first as the reusable platform baseline. The client project does not begin by building the platform from scratch. Onsite implementation configures the established platform around the actual client operation.

## First deployment scope

### NEBCA Core
- identity and access
- obligations and conditions
- evidence vault
- CAPA
- risk
- audit trail
- critical alert and escalation
- SSAL
- regulator evidence boundary

### GFCDS — Fisheries
- quota and TAC control
- vessel compliance
- landing and processing coordination
- seasonal workforce readiness
- cold-chain and product traceability
- fisheries SHEC
- fisheries regulator evidence packs
- executive fisheries view

### HICDS — Harbour Integration
- harbour event register
- shared vessel dashboard
- bunkering coordination
- landing coordination
- shared clearance
- incident and environmental events
- regulator cloud access
- commercial privacy and data boundary

## Implementation sequence

0. NEBCA Core product baseline — completed before client deployment
1. Client discovery and BA — 1–2 weeks
2. Onsite infrastructure and data foundation — 1–2 weeks
3. GFCDS configuration — 2–4 weeks
4. HICDS configuration — 2–4 weeks
5. UAT, training and regulator evidence commissioning — 2 weeks
6. Go-live and stabilisation — 2–4 weeks
